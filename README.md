# RadLex
Site for managing and curating the RSNA RadLex® radiology ontology, a set of terms for use in reporting, decision support, data mining, data registries, education, and research.

## Documentation

- [Contributing to RadLex](docs/CONTRIBUTING.md): how to propose changes to the ontology.
- [Testing RadLex.owl](docs/TESTING.md): the integrity checks run in CI, and how to run them locally.
